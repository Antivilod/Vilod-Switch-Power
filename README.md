# Vilod Switch Power (VSP) 0.8.0

VSP - приложение Windows для выбора профилей питания, ограничения FPS на поддерживаемом оборудовании и необязательного мониторинга. Публикуется исходный код версии 0.8.0 под MIT. Установщика и готовой сборки для скачивания в этом репозитории нет.

## Возможности в исходном коде

- Профили «Работа», 60/120/200/400 FPS, пользовательский, Game Boost и соревновательный.
- Управление CPU EPP/Turbo, доступным бюджетом мощности NVIDIA GPU и ограничением FPS через драйвер; логика сохранения и восстановления прежних параметров.
- Распознавание игр, поиск библиотек Steam, привязки профилей и автоматическое возвращение в режим «Работа».
- Планировщик очистки памяти, пороги памяти и изменение приоритетов выбранных фоновых процессов во время игры.
- Светлая и тёмная темы, графики доступной телеметрии CPU/GPU/RAM и необязательные расширенные датчики.
- Кадровые метрики через отдельно получаемый PresentMon; оценка энергии GPU 0 по телеметрии мощности и необязательному тарифу.

Эти возможности подтверждены чтением исходников. Тесты ядра проверяют программную логику, но не подтверждают работу каждого драйвера или оборудования. Для управления питанием требуется отдельно настроенная и проверенная служба.

## Требования и установка

Требуются Windows x64, .NET SDK 10, PowerShell 7 и интернет для восстановления NuGet-пакетов из публичного источника. Используется WPF; Linux и macOS для запуска интерфейса не поддерживаются.

1. Получите исходники репозитория и откройте его корневую папку.
2. Соберите компоненты по командам ниже или по подробной [инструкции сборки](docs/BUILD.md).
3. После публикации компонентов сборочным скриптом запустите `artifacts/source-build/app/QuietPC.exe`. Папка `monitor` должна находиться рядом с папкой `app`.
4. Для portable-хранения настроек создайте пустой `portable.flag` рядом с `QuietPC.exe`. Данные будут создаваться локально; этот флаг не устанавливает службу питания.

Автоматической установки или регистрации службы нет. Без подходящей службы управление питанием недоступно. Сообщение интерфейса о папке Install относится к прежнему частному выпуску: такой папки в публичных исходниках нет. До самостоятельных интеграционных испытаний не заменяйте рабочую службу.

## Сборка и проверки

Из корня репозитория:

```powershell
dotnet restore tests/QuietPC.Tests --configfile NuGet.public.config
dotnet build tests/QuietPC.Tests -c Release --no-restore
dotnet tests/QuietPC.Tests/bin/Release/net10.0/QuietPC.Tests.dll
dotnet restore src/QuietPC.App --configfile NuGet.public.config
dotnet build src/QuietPC.App -c Release --no-restore
dotnet restore src/QuietPC.Monitor --configfile NuGet.public.config
dotnet build src/QuietPC.Monitor -c Release --no-restore
dotnet restore src/QuietPC.Service --configfile NuGet.public.config
dotnet build src/QuietPC.Service -c Release --no-restore
```

Для сборки и публикации файлов app/monitor/service в локальную папку `artifacts/source-build/` предусмотрен скрипт:

```powershell
pwsh -NoProfile -File scripts/build-source.ps1
```

Сборка не устанавливает и не запускает службу. Если политика компьютера блокирует запуск, не отключайте защиту. Проверка ядра через установленный .NET приведена выше; успешная компиляция не гарантирует разрешение запуска приложения.

При повторной проверке 2026-11-02 на Windows x64 с SDK 10.0.401 прошли 100 тестов ядра и сборки App, Windows, Monitor, Service, исторической службы 0.3.8. Ошибок и предупреждений сборки не было. UI и оборудование повторно не проверялись. Подробности: [проверка публикации](audit/PUBLICATION-CHECK.md).

## Настройка

Откройте интерфейс, выберите профиль и настройте параметры под своё оборудование. Управление включается основной кнопкой. Начните с отключённой автоматики и проверьте восстановление параметров в испытательной среде.

В `examples/` находятся три синтетических примера: профили, мониторинг и тариф GPU. Они автоматически не применяются. Запуск, автоматика, очистка и сетевые пробы в примерах выключены; списки игр и фоновых программ пусты. Настройки, журналы восстановления, SID и сведения о вашей машине не предназначены для коммитов. Подробности: [CONFIGURATION.md](docs/CONFIGURATION.md).

PresentMon 2.4.1 необязателен и не включён. Код ищет `tools/PresentMon.exe` в папке рядом с `app`; получайте компонент отдельно из [официального проекта](https://github.com/GameTechDev/PresentMon/tree/v2.4.1) и сохраняйте его лицензию. Без него кадровые метрики недоступны.

## Ограничения версии 0.8.0

- FPS означает заданный потолок, а не обещанную производительность. Поддержка функций зависит от Windows, драйвера и оборудования.
- Энергия относится к GPU 0 и является оценкой по доступным замерам. Потребление всего ПК из розетки и полная задержка мышь-экран не измеряются.
- Совместимость с античитами не сертифицирована. Приложение не устанавливает драйверы мониторинга.
- Текущая служба в исходниках имеет собственную версию 0.4.1. В прежнем частном выпуске интерфейса 0.8.0 использовалась служба 0.3.8; её бинарник исключён. Исторические исходники находятся в `legacy/backend-0.3.8/`.
- Побитовая воспроизводимость прежнего установленного выпуска не подтверждена. Нужны испытания восстановления после падения, сна и перезагрузки, прав канала, нескольких пользователей и удаления службы. См. [RELEASE-NOTES.md](docs/RELEASE-NOTES.md).
