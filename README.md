# Vilod Switch Power (VSP)

Windows-приложение для выбора профилей питания, ограничения FPS на поддерживаемых NVIDIA GPU и мониторинга. Логотип и основные режимы сохранены.

**Версия 0.8.2: исправление CPU-политик и установщик Windows x64.** Публикация установщика разрешена только после успешной Windows CI. Фактические результаты находятся в `WINDOWS-VERIFICATION.json` и `CPU-POLICY-VERIFICATION.json` выпуска. Реальные игры, температуры и термостабильность этой версии не проверены.

## Установка готовой сборки

Откройте [выпуск 0.8.2](https://github.com/Antivilod/Vilod-Switch-Power/releases/tag/v0.8.2) и скачайте `VSP-0.8.2-Setup-x64.exe` из раздела Assets:

1. Скачайте EXE и `SHA256SUMS.txt` из одного выпуска. Проверьте SHA-256 командой `Get-FileHash .\VSP-0.8.2-Setup-x64.exe -Algorithm SHA256`.
2. Запустите установщик. Права администратора нужны для службы питания, основной интерфейс работает без повышения прав. Отдельная установка .NET не требуется.
3. Откройте Vilod Switch Power из меню «Пуск». Выберите режим и включите управление основной кнопкой.
4. Для отключения нажмите основную кнопку повторно. При выходе приложение восстанавливает собственные изменения; при потере связи служба делает это после тайм-аута.
5. Удаление доступно в параметрах Windows. Сначала восстанавливаются настройки; при конфликте удаление останавливается и сохраняет файлы для восстановления.

Установщик не заменяет существующую службу QuietPC/VSP и не переносит настройки частного выпуска. Если такая версия уже установлена, сначала используйте её штатное удаление. На компьютерах с ограничениями запуска неподписанных программ установка может быть запрещена. Не отключайте защиту Windows ради установки.

Подробнее: [инструкция установки](docs/INSTALL.md), [сборка](docs/BUILD.md), [настройки](docs/CONFIGURATION.md).

## Обновление в исходниках 0.8.3

Установщик отдельно сообщает о зарегистрированной службе QuietPC и занятом пути установки. Сообщение на русском или английском подсказывает следующий шаг. Переход с предыдущей версии по-прежнему начинается с выключения управления и штатного удаления.

Для проверки скачанного EXE или другого файла с соответствующей записью в SHA256SUMS используйте отдельную [утилиту на Rust](tools/checksum/README.md).

## Что изменилось в 0.8.2

На гибридных CPU VSP задаёт EPP и минимальное состояние процессора также для дополнительных efficiency classes 1/2, если Windows предоставляет эти настройки. После записи дополнительных параметров выполняется чтение для подтверждения; ошибки не маскируются под успех.

«Работа» отключает Turbo (0). Обычные игровые профили явно разрешают штатный Turbo (1), даже если он выключен в исходной схеме. Game Boost и другие профили с EPP 0 задают режим 2; его аппаратное поведение зависит от платформы. Это не разгон и не гарантия прироста FPS. Заводские настройки первого запуска не изменены.

## Режимы и возможности

- «Работа», 60/120/200/400 FPS, пользовательский, Game Boost и соревновательный режим.
- CPU EPP/Turbo и поддерживаемые ограничения мощности/FPS NVIDIA с журналом восстановления.
- Игры Steam и привязки профилей, необязательный переход в «Работа» вне игры.
- Мониторинг CPU/GPU/RAM, светлая и тёмная темы, необязательные расширенные датчики.
- Кадровые метрики через отдельно получаемый PresentMon 2.4.1. Он не входит в установщик.

При первой установке выбран режим «Работа», управление выключено. Автоматика, очистка памяти и возобновление управления при запуске выключены. Их можно включить самостоятельно. Настройки и журналы создаются на компьютере пользователя; чужой профиль не поставляется.

## Ограничения

FPS - заданный потолок, а не обещанная производительность. Поддержка управления GPU зависит от драйвера и видеокарты; если функция недоступна, интерфейс сообщает о частичном применении. Поддержка AMD не добавлялась. Реальное потребление всего ПК и полная задержка мышь-экран не измеряются. Совместимость с античитами не сертифицирована.

Рабочая цель - Windows x64. Автоматическая проверка установщика использует Windows Server 2025; результаты на NVIDIA и ноутбуке владельца нужно указывать отдельно. Linux и macOS не запускают WPF-интерфейс.

## Проверки и состав

В 0.8.2 добавлена Windows-регрессия EPP 90/70/0, AC/DC, дополнительных классов при их наличии, minimum 3/5, Turbo 0/1/2, активации и восстановления схемы. Тест отдельно проверяет игровой Turbo при выключенном Turbo в базовой схеме. Отсутствующие дополнительные настройки пропускаются; число реально проверенных классов записывается в отчёт. Наличие настройки Windows не доказывает наличие гибридного CPU в CI.

103 теста ядра проверяют логику программы. Перед публикацией Windows CI должна собрать установщик и проверить установку, службу, применение/восстановление питания, восстановление после сбоя службы, запуск окна и удаление. [Состав проверки 0.8.2](audit/INSTALLER-0.8.2.md).

В исходниках нет пользовательских настроек, логов, ключей, сертификатов или персональных данных владельца. Перед передачей собственных журналов и настроек проверьте содержимое. [SECURITY.md](SECURITY.md).
