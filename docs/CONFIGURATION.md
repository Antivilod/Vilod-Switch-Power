# Настройка

Сначала запустите интерфейс и настройте профили в нём. Синтетические файлы в `examples/` не содержат путей игр, SID, имён пользователей или устройств и не применяются автоматически.

- `profiles.example.json` - допустимая схема Preferences; выбран режим «Работа», запуск выключен, автоматические действия отключены. Изменения питания применяются только после явного включения управления.
- `monitoring.example.json` - базовые графики; расширенные датчики и сетевые пробы выключены, адрес пуст.
- `energy-settings.example.json` - тариф не задан. Энергия относится только к GPU 0.

Имена runtime-файлов: `profiles.json`, `monitoring.json`, `energy-settings.json`. Перед ручным редактированием закройте VSP и сделайте приватную копию своих настроек. Примеры показывают объект, а не миграцию данных.

Установленный интерфейс использует локальный каталог профиля Windows; portable использует Data рядом с приложением либо локальный запасной каталог. Служба хранит журналы восстановления отдельно в ProgramData. Не переносите чужие журналы восстановления и SID между компьютерами. Не коммитьте пользовательские файлы, историю игр, отчёты энергии, трассы ETW, дампы или логи.

Для сетевой проверки пользователь сам выбирает адрес и включает пробы. ICMP задержка - не полная задержка игры. Для датчиков CPU могут потребоваться отдельные компоненты драйвера; они автоматически не устанавливаются.
