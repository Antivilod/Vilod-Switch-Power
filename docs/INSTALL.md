# Установка VSP 0.8.1

Установщик 0.8.1 прошёл автоматические проверки на Windows Server 2025. Выпуск предназначен для дальнейшей проверки на физических устройствах; NVIDIA и ноутбук владельца в CI не проверялись.

Устанавливайте только EXE из проверенного выпуска этого репозитория. Нужны Windows x64 и права администратора для настройки службы. .NET включён в пакет. После установки запускайте интерфейс обычным способом из меню «Пуск».

Служба разрешает применение профилей только локальной учётной записи, определённой при установке. Другой администратор может проверить состояние и восстановить настройки для удаления, но не получает через этот интерфейс право выбирать профили. Если интерактивную учётную запись определить невозможно, установка использует текущую учётную запись установщика; это отдельно проверяется при развёртывании в необычной среде.

Программа устанавливается в Program Files/Vilod/VSP. Публичные настройки создаются в LocalAppData/Vilod/VSP, служебные журналы - в ProgramData/VilodVSP с доступом SYSTEM и администраторов. Имена пользователей, SID и конкретные локальные пути в поставку не включены. Журналы и настройки сохраняются при удалении.

Существующая служба QuietPC и существующая папка установки не заменяются. Это защищает другую рабочую или частную версию от случайной подмены. Сначала выключите её управление и используйте её штатное удаление. Не удаляйте журнал восстановления вручную при конфликте.

Первый запуск: проверьте возможности компьютера, выберите «Работа», включите управление и проверьте статус. Выключите управление и убедитесь, что восстановление подтверждено. Затем пробуйте игровые режимы. Недоступность GPU/FPS означает ограничение оборудования или драйвера; она не должна отображаться как полный успех.

Для удаления закройте интерфейс и откройте «Установленные приложения» Windows. Если восстановление не подтверждено, удаление остановится. Сохраните файлы, разрешите конфликт по сообщению VSP и повторите попытку. Отключать защиту Windows не требуется и не предлагается.

Готовая сборка не содержит подписанного сертификата издателя. При корпоративной блокировке запуска обратитесь к администратору, а не обходите политику.
