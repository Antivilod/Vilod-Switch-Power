# Vilod Checksum

Небольшая утилита на Rust для проверки скачанного файла по SHA256SUMS.txt. Работает с установщиком VSP и любым файлом, для которого есть запись в стандартном формате SHA256SUMS. Читает данные потоком, поэтому размер файла не ограничен размером оперативной памяти.

Из корня репозитория, с Rust 1.85 или новее:

```powershell
cargo run --locked --release --manifest-path tools/checksum/Cargo.toml -- VSP-0.8.2-Setup-x64.exe SHA256SUMS.txt
```

Сохраните оригинальное имя файла и возьмите SHA256SUMS.txt из того же выпуска. При совпадении команда возвращает 0. Повреждённый файл, отсутствующая или повторная запись возвращают 1. Поддерживаются UTF-8, BOM, LF и CRLF, а также текстовые и бинарные строки формата GNU SHA256SUMS.

Утилита сравнивает хеш с переданным списком. Для проверки используйте список из доверенного источника.

Лицензия собственного кода - MIT. Утилита использует RustCrypto `sha2` (MIT или Apache-2.0). Версии зависимостей фиксируются в Cargo.lock. Эти зависимости нужны только CLI.
