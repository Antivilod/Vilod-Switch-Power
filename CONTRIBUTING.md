# Contributing

Use synthetic data and relative paths. Build and run core tests as described in docs/BUILD.md. Keep MIT notices and upstream licensing. Do not add binaries, credentials, personal logs or generated output. New power/driver changes require integration testing and restoration tests on a disposable test system. Describe tested hardware and limitations without publishing persistent identifiers.

Use the public Git identity you intend to disclose; check author/committer, remotes, tags, notes, reflogs and all objects before making a repository public. This package has no configured remote and does not publish automatically.
